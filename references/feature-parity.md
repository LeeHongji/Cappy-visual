# 能力与验证对应

本文件核对 Cappy 的文章配图能力。开发参考不是运行时依赖；复制技能时只需本技能的文件和资产。

| 能力 / 要求 | Cappy 中的位置 | 验证方式 |
| --- | --- | --- |
| 理解正文、找认知锚点、不平均配图 | `SKILL.md` 第 1 步 | Markdown 文章 fixture 与 shot list |
| 只做建议、默认 4–8 张 / 短文 1–3 张 | `SKILL.md` 第 2 步 | 策略分支，不因建议请求自动绘图 |
| 明确生图就直接生成、每张独立 | `SKILL.md` 第 3 步 | 8 张不同结构逐张调用内置绘图工具 |
| 白底、手绘、留白、红橙蓝、少字 | `references/style-dna.md` | 成图观察和白底/尺寸检查 |
| 固定 IP 是核心动作主体 | `references/cappy-ip.md` | 用户原稿对比和逐图动作观察 |
| 8 种结构 | `references/composition-patterns.md` | 每种一张，见 `assets/examples/` |
| 从文章重新发明隐喻，不抄旧案例 | 同上 | 比对动作、主物件、布局与原例 |

| 去标题、改图、增强参与感 | 同上与 `SKILL.md` 第 4 步 | 带标题测试草稿的局部编辑；每张核心动作检查 |

| 自动发现与明确调用 | `agents/openai.yaml` | frontmatter、UI metadata 与打包检查 |

## 只为角色替换而调整的要求

黑色实心、白点眼、细腿、变形身体改成 Cappy 的白色梯形壳、椭圆脸、短手脚和稳定形体；原“不卖萌”不再禁止用户原稿已有的亲和感、挤眼或惊讶表情。场景仍避免幼稚海报与装饰性角色。

原画无须作为场景模板使用；传入原稿锁定身份与统一轮廓语言。Cappy、道具与场景的笔触力度协调，略带自然手绘感，文字使用轻手写批注。麦克风可选，不能每张强制出现。其余流程与视觉标准延续原能力。

外部链接/Notion 来源读取取决于运行环境的可用连接和权限；这次本地验证不声称已测试一个真实 Notion 账户。
