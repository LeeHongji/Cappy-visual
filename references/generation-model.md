# 生成入口与高清输出

默认使用 imagegen 技能的内置 image_gen 工具，直接进行绘图和编辑，不需要用户配置 API key。每张配图单独调用，附上原始 Cappy 角色参考；不能用手绘 SVG 或 HTML 占位图冒充完成的插画。

只有用户明确选择 API/CLI 路径时才使用相应入口，不因为尺寸或普通质量控制自动切换。如果工具不提供模型选择或模型回显，如实记录使用了内置工具，不编造具体后端模型 ID，也不把提示词中的模型名称当成调用凭据。

每次保留实际入口、引用图片、提示词、输出文件和真实像素尺寸。图像返回后复制到项目目录，原始文件继续保留。工具不可用时明确说明，不宣称已生成。

## 输出尺寸

正文插画保持 16:9，提示词优先请求 2560×1440 或 3840×2160。封面优先请求 3840×1536，留足四周安全边距。以工具实际返回的尺寸为准，交付前检查并记录；不能把插值放大、修改 DPI 或 SVG 栅格化称为原生高清生成。

清晰度不仅是像素数：在 100% 看手和接触点不糊、不粘连，在约 900px 桌面宽度与 360px 手机宽度仍能读懂角色和主要动作。小字太密时减少内容，而不是缩小所有元素。

生成或编辑之后必须执行 [视觉审核](qa-checklist.md)。模型或工具选择不能代替对原稿、肢体和实际接触关系的看图核对。
