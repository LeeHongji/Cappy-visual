# 验证记录

本轮使用 imagegen 内置工具重新生成 PNG 封面与 8 张正文插画。旧版中发现的手部与连接问题促成了更严格的审核规则；旧版通过结论不自动适用于新版。

本轮已按最终风格统一原稿轮廓与轻手写批注，并经 Kimi 独立复核：9 张图全部通过，13 个 Cappy 均完成逐角色看图检查，无阻塞项。README 首屏选用已经通过审核的三格减负图。

## 当前文件与实际尺寸

- 封面：1983×793，约 2.5:1，实际生成的 PNG，未通过 SVG 栅格化或插值放大冒充新图。
- 8 张正文图：1672×941，16:9 栅格取整高度误差 0.5 像素。
- 共 13 个 Cappy：角色状态和小漫画各 3 个，其余 6 张各 1 个，封面 1 个。
- 执行入口是内置 image_gen；工具没有回显的后端模型 ID 不作断言。

## 视觉审核流程

每次生成与编辑后都对照原稿看全图，再检查每个角色的两只手、两只脚、手臂连接、握持点和明确遮挡。检查原始尺寸后，再看桌面与手机展示宽度的识别度。出现多手、缺手、悬浮、穿插或无法说明的遮挡时必须修正，新版本重新审核。

本轮统一 Cappy、道具与场景的圆润轮廓，不采用角色粗线与场景极细线的分离风格；文字改为轻手写批注。小漫画以拼装玩具表达尝试、反馈与调整。

此前实际修正包括：删除额外手套与悬浮手、把重复手形改为连接清楚的短手臂、去掉灰色投影与道具填色、纠正反馈箭头的方向、重新放置天平两侧的标注，以及扩大分层图的留白。未通过的候选没有进入最终展示目录。

## 已执行的功能检查

| 检查项 | 范围 |
| --- | --- |
| 8 种构图 | 8 张独立 PNG，分别生成与检查 |
| 原稿身份 | 白色梯形键帽、椭圆脸、竖眼与 w 嘴；允许原稿已有的自然表情变化 |
| 局部编辑 | 本轮实际修正手部、配色、文字、反馈路径和局部布局，并在修改后重新看图 |
| 去标题与角色替换 | 先前功能测试实际执行并保留记录；不作为本轮新图的视觉通过证据 |
| 不覆盖保存 | 修改候选另存版本，旧原图归档；先前同名文件另存测试确认原文件 SHA256 未变 |
| 短文策略 | 只给建议时不生图，短文默认 1–3 张 |
| 文件与引用 | 检查图片可打开、尺寸真实、Markdown 相对链接和角色参考存在 |
| 独立复制 | 验证技能及原稿资源不依赖开发参考目录 |

像素和哈希检查只用于确认文件与版本，不能证明手部结构或美感。正式交付还需要实际看图的独立审核。

## 使用边界

工具不可用、只有会话图而无本地路径、外部网页或 Notion 权限不足、连续不可修复失败等分支仅做了规则检查，没有连接外部账户或伪造工具故障。生成与编辑有随机性，之后每次出图仍须审核。

本地保留原始生成文件、提示词、修改版本和审核记录；公共仓库提供选定成图与这份摘要，不发布机器路径、失败草稿和原始运行日志。
